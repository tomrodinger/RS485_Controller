# Unfinished design archive

This directory contains hardware work that predates the datasheet task and is retained as an unfinished development archive. Its library files and manufacturing exports are not the released RS485 Controller design.

The released product remains **RS2 / PCB revision 0.5** in [`../0.5`](../0.5), covered by datasheet document revision 1.0. Do not interpret this directory name as a released hardware version or use these fabrication exports as the production package for PCB 0.5.
